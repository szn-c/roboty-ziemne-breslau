# Ekstrakty tekstu z dokumentów

Tekst wyciągnięty programem `prace/obliczenia_v1/_skrypt/wyciagnij_tekst_dokumentow.py` (PDF: PyMuPDF; DOC: odczyt tabeli fragmentów Worda).
Służy do szybkiego przeszukiwania. Nazwy plików .txt pochodzą z wczesnych nazw dokumentów (mogą różnić się od nazw w repo).
**Ograniczenia:** tabele są spłaszczone, kolejność linii w kartach otworów bywa zaburzona, rysunki (raster) nie mają tekstu.
Przy wątpliwościach sprawdź oryginał. Dla nowych dokumentów uruchom program ponownie.
